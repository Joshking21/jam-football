# Club reference (made 23 Nov at the user's request)

`club.png` is the target; `index.html` is its static source (it uses the shared `base.css` and `base.js`). Build §11.13 Club and §12.17 to match it. Where this file and the SPEC differ, this file wins on layout and look; the SPEC wins on rules and numbers.

- **The ledger** (an open book with ruled pages):
  - **Left page:** the balance in large type, a weekly in/out bar chart by matchday (home games marked, since gate income only comes at home), and one handwritten blue note from the finance director.
  - **Right page:** "This week" line items (§12.10), budgets, wage room, and prize money at the current position.
- **From the boardroom:** a letter from the owner with a quote from board-review templates, the board confidence meter with the sack line (red tick at 25), the expectation, and buttons: Ask for more budget, Talk about the stadium (both open boardroom talk scenes in M6b).
- **The staff:** four pinned photo cards (printed portrait, name, role, stars, effect in words). Replace one per window round (§12.17.1).
- **The dressing room:** the cohesion meter with this week's reasons (+/-) and the three leader cards (§12.17.5).
- **The fans:** letters-page quotes with names and seats; mood and change.
- **The stadium:** capacity, % full, and attendance bars per home game.

All names, numbers and colours in the image are **sample data**. Always use the game's real data.
