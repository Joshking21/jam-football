# Load a season reference (made 23 Nov at the user's request)

`load.png` is the target; `index.html` is its static source. It covers the Load screen (§11.2 Title → Load, §20). Where this file and the SPEC differ, this file wins on layout and look; the SPEC wins on rules and numbers.

- Over the blurred title scene. Four slots: the autosave (corner ribbon) plus 3 manual slots.
- **Each save** is a matchday-programme card in its club's colours: crest, club, big league position, points, matchday, manager, season, time played, and a mini line of league position so far. Buttons: Load (primary), Export, Delete (not on the autosave).
- **Empty slots** are dashed, with a hint.
- **Footer:** where saves live, and **Import a save file**. `Esc` goes back.

People in the scene images are drawn stand-ins for the M6b 3D characters (ART-DIRECTION). All names, numbers and colours are **sample data**.
