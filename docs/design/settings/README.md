# Settings reference (made 23 Nov at the user's request)

`settings.png` is the target; `index.html` is its static source (open with `#settings` to see Settings). It covers §11.22 Settings. Where this file and the SPEC differ, this file wins on layout and look; the SPEC wins on rules and numbers.

- A modal over the current scene: a navy side menu (Audio, Gameplay, Graphics, Accessibility, Data, keys 1–5) and a paper pane.
- **Audio:** sliders for Master, Music, Crowd, Commentary, Effects (with what each covers), Voices on/off, and a test line.
- **Gameplay:** default match speed, auto-continue after highlights, confirm Instant result, **coach walks between rooms**, **Knocks** (Ask me / Always take off / Play on if under 15').
- **Graphics:** quality Auto/Low/Medium/High, show FPS.
- **Accessibility:** reduce motion, larger text, colour-blind attribute colours, captions size.
- **Data:** save to a slot, export, import, delete saves.
- Each row has a plain-language sub-line. "Reset to default" and "Done (Esc)".

People in the scene images are drawn stand-ins for the M6b 3D characters (ART-DIRECTION). All names, numbers and colours are **sample data**.
