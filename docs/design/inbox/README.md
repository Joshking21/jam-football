# Inbox reference (made 23 Nov at the user's request)

`inbox.png` is the target; `index.html` is its static source (it uses the shared `base.css` and `base.js`). Build §11.14 Inbox and §12.11 to match it. Where this file and the SPEC differ, this file wins on layout and look; the SPEC wins on rules and numbers.

- The desk seen from above: a **pile of memos** on the left, slightly rotated and overlapping, with the newest on top. Each memo has a coloured left edge by sender (Agent amber, Discipline red, Board blue, Medical green, Scouting grey, Theo navy, Press taupe), the sender type, headline, one-line summary, day, an unread dot, and an **ACTION** stamp when it blocks Continue.
- Sender tray filters: All, Needs action, Board, Players, Medical, Scouting, Press.
- **The open item** is a full letter on the right with its own letterhead (agency, club, league, hospital...), date, headline, body in serif, a terms box when relevant (contract talks, bids), a signature, and the actions along the bottom with Theo's one-line advice.
- Actions that start a conversation open the talk scene (§11.25.5). The inbox keeps the record.

All names, numbers and colours in the image are **sample data**. Always use the game's real data.
